智慧管网物联网监控中心
技术栈：Vue TypeScript ECharts Element Plus
IoT 实时监控大屏 Demo — 一屏管全网
项目简介
智慧管网物联网监控中心 是一个面向城市管网基础设施的 IoT 实时监控大屏演示项目。通过可视化手段，帮助运维人员全面掌握管网设备的运行状态、环境指标和告警信息，实现"一屏管全网"的运维目标。
Demo 说明：本项目所有数据均为前端模拟生成，不对接真实后端接口。适用于项目提案/汇报演示、UI 设计评审参考、前端开发模板基线。

功能模块

1. 顶部标题栏
   平台品牌标识（IoT Platform）
   居中大标题 "智慧管网物联网监控中心"
   实时时钟显示（每秒刷新）
   告警铃铛图标 + 未读告警角标
2. 左侧面板 — 统计概览
   模块 图表类型 说明
   设备状态分布 环形饼图 实时展示在线/离线/告警设备占比
   近 7 日告警趋势 柱状图 按周维度统计告警数量变化
3. 中间主区域 — 核心监控
   KPI 指标卡片 × 4
   设备总数、在线设备数、告警数量、采集频率
   每张卡片带趋势箭头（↑/↓）和变化值
   温湿度时序监测
   双 Y 轴折线图 + 数据缩放滑块
   实时流式数据，每秒推入新数据点
   最多保留 30 个数据点（FIFO）
   带 LIVE 呼吸灯标识
   管网压力仪表盘
   0~100 MPa 量程
   三色区间：绿色（正常）/ 黄色（预警）/ 红色（告警）
   实时指针动画
   设备运行状态明细
   支持设备编号搜索、手动刷新
   数据列：设备编号、温度、湿度、压力、运行状态、上报时间、操作
   告警行高亮、离线行半透明
4. 右侧面板 — 告警 & 环境
   实时告警列表
   三级告警：critical（红）/ warning（黄）/ info（蓝）
   带入场/离场动画效果
   最多保留 8 条告警记录
   环境综合指标
   雷达图展示五维指标：温度、湿度、压力、振动、流量
   多边形网格 + 渐变填充
